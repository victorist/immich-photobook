# Immich и Immich Book

Персональный self-hosted фотоархив на базе [Immich](https://immich.app/) с веб-приложением **Immich Book** для создания PDF-фотокниг из альбомов. Проект объединяет сервер хранения фотографий, поиск и обработку медиа с редактором макета книги.

## Цели проекта

1. Хранить и просматривать личную медиатеку на собственном сервере с помощью Immich.
2. Организовывать фотографии в альбомы и находить их по содержимому, в том числе русскоязычными запросами.
3. Создавать из выбранного альбома настраиваемый макет фотокниги и экспортировать его в PDF.
4. Сохранять оригиналы фотографий в Immich; Book получает медиа по API и не изменяет оригинальные файлы.

## Состав и архитектура

Проект запускается через Docker Compose и включает:

| Сервис | Назначение | Порт на хосте |
| --- | --- | ---: |
| `immich-server` | Web/API Immich | `2283` |
| `immich-machine-learning` | Smart Search, распознавание и ML-задачи | внутренний порт `3003` |
| `database` | PostgreSQL с расширениями Immich | внутренний порт |
| `redis` | Очереди фоновых задач | внутренний порт |
| `immich-book` | React/Vite-приложение, собранное и обслуживаемое Nginx | `3080` |

Immich Book — отдельный frontend без собственной базы данных. Он подключается к Immich с API-ключом пользователя. Для текущего развёртывания frontend собран с base path `/book/`; внутренний Nginx обслуживает UI и проксирует `/api/` к Immich по адресу `http://192.168.1.56:2283/api/`.

Внешние адреса текущей установки:

- Immich: [https://mypawka.neurocat.ru](https://mypawka.neurocat.ru)
- Immich Book: [https://book.neurocat.ru](https://book.neurocat.ru)

Конфигурация доменов, reverse proxy, адреса API и GPU зависят от локальной сети. Перед переносом на другой сервер проверьте соответствующие значения в [`docker-compose.yml`](docker-compose.yml), [`immich-book-build/Dockerfile`](immich-book-build/Dockerfile), [`immich-book-build/nginx.conf`](immich-book-build/nginx.conf) и конфигурации внешнего reverse proxy.

## Требования

- Linux-сервер с Docker Engine и Docker Compose plugin.
- Достаточно места для оригиналов, миниатюр, базы данных и резервных копий.
- Для текущей CUDA-конфигурации — NVIDIA GPU, совместимый драйвер и настроенный NVIDIA Container Toolkit.
- Домен/TLS и reverse proxy — если сервисы должны быть доступны извне.

Текущий Compose использует `ghcr.io/immich-app/immich-machine-learning:${IMMICH_VERSION:-release}-cuda` и резервирует NVIDIA GPU для ML-сервиса. Без совместимой NVIDIA-конфигурации нужно выбрать CPU-образ или подходящий accelerator-вариант из [официальной документации Immich](https://docs.immich.app/features/ml-hardware-acceleration).

## Установка и запуск

1. Получите репозиторий и перейдите в его корень:

   ```bash
   git clone <URL-этого-репозитория>
   cd immich-app
   ```

2. Создайте локальный `.env` из шаблона и задайте секреты:

   ```bash
   cp .env.example .env
   ```

   Проверьте как минимум `UPLOAD_LOCATION`, `DB_DATA_LOCATION`, `IMMICH_VERSION` и `DB_PASSWORD`. Для `DB_PASSWORD` используйте только символы `A-Z`, `a-z`, `0-9`, как требует шаблон Immich. Не добавляйте `.env` в Git.

3. Убедитесь, что каталоги хранения существуют и доступны Docker:

   ```bash
   mkdir -p upload postgres
   ```

4. Проверьте конфигурацию Compose и запустите сервисы:

   ```bash
   docker compose config
   docker compose up -d
   ```

5. Откройте Immich по адресу сервера и завершите первоначальную настройку администратора.

6. Откройте Immich Book по настроенному адресу, например `https://book.neurocat.ru`, и подключитесь к Immich через API-ключ.

Для пересборки только Book после изменения его исходников или Dockerfile:

```bash
docker compose up -d --build immich-book
```

Основной Immich обновляйте по официальным инструкциям [Docker Compose installation](https://docs.immich.app/install/docker-compose), проверяя совместимость Compose-файла с конкретным релизом.

## Адреса и проксирование

Сервисы публикуются на хосте Immich:

- Immich API/UI — порт `2283`.
- Immich Book — порт `3080`.

В текущей схеме внешний reverse proxy направляет домен `book.neurocat.ru` на порт Book, а домен Immich — на `2283`. В браузере Book обращается к Immich через same-origin путь `/api/`, который Nginx Book проксирует на внутренний адрес сервера. Такая схема позволяет избежать прямого cross-origin запроса и CORS-проблем.

Если изменяется LAN IP Immich, замените `192.168.1.56` в `immich-book-build/nginx.conf` и пересоберите контейнер:

```bash
docker compose up -d --build immich-book
```

Не публикуйте Immich API или Book без TLS и подходящих правил reverse proxy. API-ключ вводится в браузере и хранится в его `localStorage`; используйте только доверенный домен и не передавайте ключ в логах, скриншотах или сообщениях.

## Подключение Immich Book

Создайте API-ключ в Immich: **Account Settings → API Keys**. Для Book необходимы разрешения на просмотр альбомов и медиа (в текущем Immich это обычно `album.read`, `asset.read` и `asset.view`; для fullsize/download может требоваться разрешение на скачивание оригиналов, в зависимости от версии Immich).

Для текущей production-сборки настроен same-origin proxy, поэтому поле **Server URL** предварительно заполнено адресом Immich и заблокировано для изменения. Введите только API-ключ. В локальной/development-сборке без `VITE_IMMICH_PROXY_TARGET` укажите в **Server URL** корень Immich, например `https://mypawka.neurocat.ru`, без `/api` в конце.

- **API Key** — созданный ключ Immich. Кроме чтения альбомов и просмотра assets, для запроса оригиналов/fullsize может понадобиться permission `asset.download`; точные permissions зависят от версии и политики доступа Immich.

При production-сборке с настроенным same-origin proxy frontend использует `/api` на домене Book. После успешного подключения можно выбрать альбом и перейти к редактору.

## Настройки фотокниги

Настройки макета можно менять в верхней панели редактора. Большинство глобальных значений сохраняются в браузере; индивидуальные изменения раскладки и порядка — отдельно для альбома. Очистка данных сайта/`localStorage` удалит эти настройки.

### Page

- **Width / Height** — пользовательские размеры одной страницы в пикселях макета; по умолчанию 2515 × 3260 px. Допустимый диапазон каждого поля — 1000–10000 px. Текущая панель задаёт размеры числами, без отдельного выбора A4/Letter/A3.
- **Combine Pages** — объединяет две соседние страницы рядом на одном широком PDF-листе. Это режим разворотов, а не типографский спуск полос. Для типографии обычно запрашивают отдельный PDF-лист на каждую страницу; включайте развороты, только если типография просит именно их.

### Layout

- **Margin** — внешний отступ страницы.
- **Row Height** — целевая высота ряда фотографий.
- **Spacing** — расстояние между фотографиями.
- Страница макетируется в системе 300 px/in; перед размещением в PDF размеры переводятся в PDF points.

### Presentation

- **Exclude Videos** — исключает видеоресурсы из фотосетки (включено по умолчанию).
- **Show Dates** — показывает даты съёмки.
- **Show Descriptions** — выводит описания фото из метаданных Immich.
- **Cover Page** — добавляет отдельный титульный лист первым в PDF и показывает его в live preview. На обложке выводятся название и описание альбома, число фотографий, фото альбома/первое фото и нижняя подпись `NEUROCAT & IMMICH PHOTOBOOK`.
- **Font Size** — размер подписей/дат.

Титульный лист — внутренняя первая страница PDF, а не типографский обложечный разворот с задником, корешком и лицевой стороной.

### Настройка фотографий

- Перетаскивайте границы фотографии, чтобы изменить её отображаемое соотношение сторон.
- Перетаскивайте фотографию, чтобы изменить порядок.
- Нажимайте описание на фотографии, чтобы менять позицию подписи.
- Кнопки выравнивания применяются отдельно к страницам. По умолчанию нечётные страницы выравниваются вправо, чётные — влево; старые несовместимые значения выравнивания мигрируют при открытии альбома.

## PDF и качество изображений

При **Generate PDF** Book получает для фотографий Immich endpoint `thumbnail?size=fullsize`; для web-совместимых форматов Immich может отдать оригинал, а для RAW/HEIC — подготовленное полноразмерное представление. Для доступа к оригиналу может требоваться `asset.download`. Видео при включённом показе остаются на preview, так как PDF-встраивание здесь рассчитано на изображения.

Для HEIC/HEIF и RAW (например, NEF) Immich должен предварительно создать fullsize-версию, если Book сообщает, что ему вернулся только preview. Чтобы фотографии передавались в PDF в высоком разрешении, в интерфейсе Immich администратора необходимо

1. Перейти по **Administration → Settings → Image Settings → Fullsize Image Settings** и включить генерацию полноразмерных изображений, задав подходящий формат JPEG.
2. Сохранить настройку.
3. Запустить генерацию/перегенерацию thumbnails для соответствующих активов в **Administration → Jobs**.
4. После завершения повторить создание PDF.

Скорость подготовки зависит от размера альбома, размера изображений, диска, сети и конвертации RAW. Во время подготовки показываются счётчик и имя текущего файла; скачивание ограничено таймаутом. Blob-изображения кэшируются в памяти вкладки, чтобы повторный рендер документа не скачивал их повторно.

Важно различать геометрию страницы и эффективное разрешение изображения. Макет рассчитывается при 300 DPI, но фактическое разрешение каждой фотографии определяется размером полученного fullsize-файла и площадью, которую она занимает на странице. Например, чтобы напечатать кадр шириной 8 дюймов при 300 DPI, ему нужно около 2400 пикселей по ширине. Увеличение меньшего источника дополнительных деталей не создаёт.

PDF использует `@react-pdf/renderer`; поддерживаемыми входными форматами изображения являются JPEG и PNG. Необработанные HEIC/NEF напрямую туда не передаются: их совместимую полноразмерную версию должен подготовить Immich.

`Combine Pages` объединяет две страницы на одном PDF-листе. Это не режим экспорта отдельной типографской обложки и не автоматический спуск полос. Перед печатью уточните у типографии формат страниц, вылеты, цветовой профиль, требования к корешку и необходимость отдельного файла переплётной обложки.

## Семантический поиск и GPU

В Immich семантический поиск (Smart Search) строит embeddings изображений и сравнивает их с текстовым запросом. Для русскоязычных запросов лучше использовать мультиязычную модель.

В Immich v3 модель настраивается администратором: **Administration → Settings → Machine Learning Settings → Smart Search → Model Name**. Для смешанных русских и английских запросов используется `ViT-SO400M-16-SigLIP2-384__webli`; в таблице Immich для русского у неё Recall 84,54%. После смены модели необходимо сохранить настройку и запустить **All** рядом с **Smart Search** на странице **Administration → Jobs**, чтобы пересчитать embeddings. Пока задача не завершилась, результаты могут быть неполными.

Текущая установка использует ML image с суффиксом `-cuda` и NVIDIA GPU. Наличие GPU в контейнере ещё не означает постоянную загрузку: GPU работает во время inference и может простаивать между заданиями. Контейнер использует ONNX Runtime CUDA Execution Provider; проверять загрузку лучше во время активной обработки.

Параметр concurrency для Smart Search находится в **Administration → Settings → Job Settings**. Увеличивайте его постепенно: concurrency повышает пропускную способность всей очереди, но увеличивает нагрузку на GPU/CPU и память, а не ускоряет отдельный запрос. Наблюдайте за температурой, VRAM и отзывчивостью Immich.

## Резервное копирование и обновление

Храните резервные копии отдельно от рабочего каталога:

- `DB_DATA_LOCATION` — база данных Immich.
- `UPLOAD_LOCATION` — оригиналы, библиотека, миниатюры и другие медиафайлы.
- `.env` и актуальная версия `docker-compose.yml` — параметры развёртывания и секреты.

Перед изменением версий сделайте согласованную резервную копию БД и файлов.

Обновляйте Immich по официальному [руководству установки](https://docs.immich.app/install/docker-compose); не переключайте теги контейнеров без сверки совместимых версий сервера, ML, базы данных и Compose.

## Диагностика

Просмотр состояния и логов:

```bash
docker compose ps
docker compose logs --tail=200 immich-server
docker compose logs --tail=200 immich-machine-learning
docker compose logs --tail=200 immich-book
```

Пересборка Immich Book:

```bash
docker compose up -d --build immich-book
```

Проверка GPU на хосте и из ML-контейнера:

```bash
nvidia-smi
docker exec immich_machine_learning nvidia-smi
docker exec immich_machine_learning /opt/venv/bin/python -c 'import onnxruntime as ort; print(ort.get_available_providers())'
```

Для CUDA среди providers ожидается `CUDAExecutionProvider`. Логи Immich ML показывают, какие providers выбраны для ONNX-модели. `nvtop` в простое может показывать 0% — наблюдайте во время задания Smart Search.

Частые причины проблем с PDF:

- `HTTP 401` при подключении — проверьте API-ключ и его permissions.
- Необычный состав фото — Book должен запрашивать `albumIds: [album.id]` в Immich Search API.
- HEIC/NEF возвращает только preview — проверьте Fullsize Image Settings и завершение генерации изображений в Immich.
- PDF generation зависает — смотрите имя текущего файла, сообщение таймаута, доступность `/api` и логи Immich.
- PDF-рендерер сообщает о шрифте — обновите Book и проверьте консоль браузера; в проекте Latin и Cyrillic Roboto регистрируются раздельно, также зарегистрирован совместимый alias `Roboto`.
